## CGT Calculator

This website is an Australian CGT Calculator that assists in the calculation of capital gains
for Australian individuals, trusts and SMSF's.

The website is hosted at https://www.cgt-calculator.com/

The website is for guidance purposes only and does NOT provide financial advice that should be trusted or acted upon.

This is a [Next.js](https://nextjs.org/) project bootstrapped with [`create-next-app`](https://github.com/vercel/next.js/tree/canary/packages/create-next-app).

## Getting Started

First, Install dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
